# المراسلات خطوة بخطوة

دليل عربي مستقل بفصل تطبيقي واحد و32 خطوة. يحافظ على تصميم دليل التفتيش ونمط «لماذا؟ ← قيم الحقول ← التطبيق ← تحقق»، ويستخدم الوزارة والوحدات والمناصب والأعضاء أنفسهم. يبدأ بتجهيز الموارد البشرية والصلاحيات، ثم دورة كتاب داخلي، ثم الوارد والإحالة والإفادة والرد والصادر والتسليم، ثم الأضابير والتعاميم والتفويض والأرشفة والمتابعة وتمرين إتقان جديد.

## افتح الدليل

من جذر المشروع:

```powershell
npm.cmd --prefix guides run build:correspondence
npm.cmd --prefix guides run dev:correspondence
```

المعاينة: http://127.0.0.1:4324/ar/ . يمكن أيضاً فتح `site/ar/index.html` مباشرة بعد البناء. ومن داخل هذا المجلد: `npm run build` ثم `npm start`.

المحتوى في `chapters/01-correspondence.tex`، واختيار الفصل في `main.tex`. ملفات `site/` مولدة؛ لا تعدّلها مباشرة. المحلل والعارض والثيم نسخ مستقلة من دليل التفتيش، حتى يعمل الدليل وحده. لا توجد تبعية تشغيل على تطبيق كيان أو اتصال به. مفتاح تقدم القراءة مستقل عن دليل التفتيش والدليل العام.

## مرجع المنظمة وحدود السيناريو

- `review/organization-reference.json` نسخة من المرجع الموثق لدليل التفتيش بتاريخ 2026-11-06، وليس استعلاماً حياً جديداً. يحفظ الأسماء والتبعية والتعيينات المرجعية.
- أسماء الفريق والوزارة والمنشآت من ذلك المرجع. نوع التدريب والديوان والترويسة والكتب وتوزيع صلاحيات الديوان والأرشفة اقتراح تدريبي في النص؛ لا نزعم وجودها أو تفعيلها في المنظمة.
- المصدر العملي للإجراءات هو الشيفرة المحلية مع صفحات المراسلات في الدليل العام. راجع `review/source-coverage.md` لمعرفة الملفات التي استندنا إليها.
- الصور الثلاث المنشورة ملتقطة من المنظمة نفسها بتاريخ 2026-11-09: `org-correspondence-tray` و`org-correspondence-compose` و`org-correspondence-types`. فُحصت بصرياً وتحمل علامات مرقمة ومفاتيحها في النص. لا تستخدم صور الدليل العام المأخوذة من test2 بوصفها صوراً لهذه المنظمة. الرسم المنشور توضيحي وموسوم بذلك.
- لم تُنفذ دورة إرسال أو اعتماد حية، ولم تُغيّر بيانات المنظمة. لا نحتاج إلى تغيير التطبيق نفسه لهذا العمل التحريري؛ التحقق الفعلي المحلي يخص تفاعل الدليل وتصميمه وروابطه. تجربة إجراءات المراسلات بحسابات الفريق تبقى تحققاً منفصلاً، وليست نتيجة الاختبارات المحلية.

## التحقق

```powershell
npm.cmd test
npm.cmd run verify
```

اختبارات الدليل المركزة تفحص الصفحات العربية والروابط والمراسي وتفرّد المعرفات وتطابق أسماء الفريق ووجود نتيجة تحقق في كل خطوة والرسم التوضيحي. اختبار المتصفح يستخدم Edge وPlaywright Core، ويتحقق من البحث والتنقل وحفظ تقدم القراءة وإعادة التحميل وعرض جميع الخطوات في مقاسي 1440 و390 وبالمظهرين. التقرير `review/browser-verification.json` والصور `review/screenshots/`.

يعيد سكربت المتصفح استخدام حزمة Playwright المثبتة في `../inspection/tools` إذا لم تتوفر محلياً. لتشغيله مستقلاً: `npm install --no-save playwright-core@1.64.1` مع وجود Microsoft Edge.

## التصوير من المنظمة

محاولة التصوير الموثقة في `review/capture-report.json` للقراءة فقط. سكربت `review/capture-org.mjs` يستخدم جلسة التصوير المحلية لدليل التفتيش دون كتابة بيانات اعتماد في المصدر، ويحظر طلبات تعديل بيانات المنظمة. لا ينشر صورة إلا إذا ظهرت كل عناصرها المطلوبة، وتبقى الصور التشخيصية خارج الموقع المنشور.

ظهر أولاً عرض مخزّن دون اتصال، ثم نجح التصوير بعد السماح بالوصول الشبكي. الحساب المتاح لا يشغل منصباً فعّالاً بحسب تنبيه إنشاء المراسلة؛ لذلك صورة الإنشاء مثال واضح على نقص متطلب، وليست إثباتاً لحفظ أو إرسال. لم نغيّر تعيينه ولم نختبر إرسالاً بحسابات الفريق. لا يشمل هذا التسليم صور النتائج الحية لمراحل التوقيع والتسليم والأرشفة.

## الفصل الثاني: مثال من الواقع (مديرية الشركات)

`chapters/02-companies-example.tex` يطبّق الأدوات على معاملتين حقيقيتين في وزارة الاقتصاد والصناعة: تصديق النظام الأساسي لشركة محدودة المسؤولية، وتسجيل تنازل عن حصص في سجل الشركاء. يضيف ثلاث وحدات تحت «الإدارة العامة للتجارة الداخلية وحماية المستهلك» وخمسة مناصب وخمسة أعضاء تجريبيين وثلاثة أدوار، دون تغيير فريق الفصل الأول.

الحقيقي فيه: أسماء الجهات، وتسلسل المعاملة (طلب ← تدقيق ← نواقص ← استكمال ← قرار)، وصيغة «يُصدّق النظام الأساسي لشركة … المحدودة المسؤولية» المنشورة في الجريدة الرسمية، وأن التنازل يتم أمام الكاتب بالعدل أو موظف المديرية وفق نموذج الوزارة، ولا يكتسب المتنازَل له صفة الشريك قبل قيده في سجل الشركاء (المرسوم التشريعي 29 لعام 2011). التدريبي فيه: الأشخاص والشركة والأرقام والمبالغ، وتوقيع مدير الشركات للقرار بصفة المفوَّض. لم تُنفذ هذه الدورة على منظمة حية بعد.
